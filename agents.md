# Sitio web de un centro dfe fp 

Este sitio web es de prueba y se usara en clase de desarrollo de interfaces web.
Consiste en un sitio web para un centro formativo de fp.

## Tecnologias 
- Fronted
    - html5 (Moderno)
    - CSS3
    - Vanilla Javascript
- Backend
    - Node.js
    - Extress 4.22.3
    - Plantillas EJS

## arquitectura
- Todo en una unica pagina index, dividido por secciones

## contenido
-El contenido debe ser realista
-el contenido debe estar en ingles
-las imagenes por defecto son de picsum.photos 

## Conversiones del lenguaje
- usa ingles para variables y funciones

## limitaciones 
- no usar grind
